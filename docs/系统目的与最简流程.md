| 维度实际值 | 原模型从本方原文读出的具体内容 | 某一天、人民币、应收账款中按单项计提的范围 |
| 本格身份证 | 本格的标准对应与模型直接确认的身份信息 | 同一余额槽位在不同业务范围、不同期间角色下不能混为同一事实 |
| 单元格原值 | 本次机械搬运的内容 | 数字、文字、日期、原空白、原公式或按既有依据读取的原公式结果 |
| 物理位置 | 原格在Excel与Word中的位置关系 | 表号、行列、合并起点、既有位置关联 |

标准编号相同不代表所有业务格都可以互填。需要区分的语义必须在原模型的本格识别结果中直接确认，不能等到程序比较时再推断。原值不参与身份的选配或消歧。原值相同也不能证明语义相同。

维度未知不否定已经明确的槽位。空白业务格仍须识别，空白成员名称不等于没有业务位置。未知只影响相应维度和相关动作，不要求把标准中所有字段填满。
