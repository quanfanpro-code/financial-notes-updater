# 📘 附注自动更新系统使用说明

**把需要更新的附注和本期数据交给程序，先弄清每一项数据的财务含义，再把正确的数据、日期和名单写进新的附注副本。**

你不需要会编程，也不需要自己写识别提示词。这份说明从“准备什么文件、打开哪个窗口、点哪个按钮”讲起，再解释程序为什么这样处理。

📅 本说明更新于 **2026年10月24日**。

🚧 **当前仍是开发中的版本。** 已用另一套示例 Word、Excel 从正常入口执行识别、两个合集、匹配和副本生成，并实际完成预付款、固定资产及无形资产名单扩展。已有答复能够复用，不必重问模型。但部分自然文字中的字段和关系仍没有完整接入，另有原文确实缺失的内容；尚不能承诺换任意资料都能自动处理完整。下面会分别说明操作方法和当前限制。

## 🎯 二、这个软件到底要帮你完成什么

假设你手里有：

- 一份上一年的财务报表附注，表格、文字和排版已经整理好。
- 一份本期的数据工作簿，里面有余额、发生额、账龄、股东名单等信息。
- 已经确定的更新要求，例如换到本期、更新名单、保留某些原值。

你希望得到的是：**按这些要求更新好的整份附注副本，能够看出数据从哪里来，下一次还可以接着用。**

程序的工作分成五件事：

1. **拿到附注中的表格。** 如果起点是 Word，就先读取原始表格和正文，保留与 Word 的位置关联。
2. **读懂附注需要什么。** 每一个待更新位置，包括应该保留的空白位置，都要放在真实表头和上下文中理解。
3. **读懂新资料能提供什么。** 先了解新资料的整体编排，再找附注需要的相关内容。
4. **把两边接起来。** 根据已经识别的含义和你的更新要求，安排来源、日期、名单及必要的行列变化。
5. **生成新文件。** 从确定的来源取值，写到新的表格和附注副本中。

💡 **“已经识别”“已经找到对应”“已经生成副本”是不同的进度。** 看到识别结果保存成功，不代表附注已经更新。

### 这不是简单的同名复制

例如，两张表都出现“银行存款”：

- 第一张写的是“期末余额”。
- 第二张写的是“本期增加”。

它们名称相同，但意思不同，不能直接互相填数。

又例如，两张表都出现“合计”，一张是存货合计，另一张是某一种存货的合计。只有弄清各自包括哪些内容，才能判断能不能对应。

## 🧩 三、先认识几个词，后面就不会看糊涂

### 1. A：等着被更新的一边

**A 就是附注表格。**

它通常来自旧 Word 附注，也可以是已经准备好的 Excel 附注表格。你可以把它理解成“这次要往哪里填”。

这里的“A”只是两份资料的区分名称，不是 Excel 的 A 列。

### 2. B：提供本次数据的一边

**B 就是更新数据表。**

它可以包含试算、余额明细以及其他附注数据。你可以把它理解成“这次从哪里拿”。

这里的“B”也不是 Excel 的 B 列。

### 3. 金标准：统一解释财务含义的参照资料

金标准告诉模型：

- 有哪些已经定义好的财务项目。
- 每个项目具体是什么意思。
- 需要用哪些信息区分不同情况。
- 哪些范围和关系已经有明确的定义。

它不负责替你编造原表没写的事实，也不是一份可以照抄金额的标准答案。

**识别时查找相符或最接近的标准；如果实际含义还有差别，就保留差别，不能为了选上一个编号把它说成完全一样。**

### 4. 槽位、维度、维度值：分别在说什么

用“银行存款余额”举例：

| 名称 | 大白话 | 例子 |
|---|---|---|
| 槽位 | 这是什么财务项目 | 银行存款余额 |
| 维度 | 还要从哪几个方面区分 | 日期、币种、公司、报表口径等 |
| 维度值 | 本次具体是什么 | 2025年12月31日、人民币、某公司、单体报表等 |

**年份变了，通常是日期这个维度的值变了；股东换了，通常是投资者这个维度的值变了。不能因此把原来的财务项目当成一个全新项目。**

具体一个槽位需要哪些维度，以金标准的完整定义为准。上面的表只是帮助理解，不是给所有项目统一规定字段。

### 5. 关系：哪些信息属于谁

例如：

- 这一列是本期，还是比较期。
- 这个期间标题适用于哪几列、哪些数据。
- 某个“其中”项目属于哪个父项。
- 合计包含哪些明细。
- 两处不同说法是否已经明确表示同一范围。

这些含义首先依据金标准已有定义，再结合实际资料由模型在识别阶段确认。后面的程序只能使用已经保存的关系，不能临时猜。

### 6. 两个合集：两份已经读懂的记录

**A合集记录附注这一边的含义，B合集记录更新数据这一边的含义。**

每份合集保存本次识别出来的标准对应、实际维度、明确关系、原位置、原答复和仍不知道的内容。空白位置也要保留。

窗口中仍使用以下名称：

| 本说明里的叫法 | 窗口里的名称 |
|---|---|
| A合集 | 附注表格语义映射 |
| B合集 | 更新数据语义映射 |
| 更新安排 | 单元格对应清单 |

📌 **保存成合集，不等于把未知补齐。** 已知内容照常保存，未知内容也照实留下。

### 7. 位置关联：Excel 怎样找到原来的 Word 表格

它记录提取后的 Excel 位置，对应 Word 中的哪张表、哪个位置。

如果只保留 Excel，丢了配套的位置关联，程序不能单凭“这里也叫合计”就猜回 Word 的写入位置。

## 📂 四、使用前准备什么

### 先分清四类材料

| 材料 | 用处 | 什么时候需要 |
|---|---|---|
| 原始 Word 附注 | 提供原来的表格、上下文和排版 | 从 Word 开始、最终要生成 Word 副本时 |
| 附注 Excel 表格 | 接收本次更新内容 | 识别附注及后续处理时 |
| 本期更新数据表 | 提供新数据和相应说明 | 识别更新数据及取值时 |
| 已有成果文件夹 | 保存合集、位置关联、更新清单及其配套材料 | 接着上次工作做时 |

当前窗口选择 Word 时使用现代 Word 文档格式，选择表格时接受常用 Excel 工作簿和含宏工作簿格式。**不要只把旧格式文件改个扩展名冒充新格式。**

### 给程序完整的业务上下文

保留原资料里的：

- 公司名称和报表口径。
- 年度、日期和期间表头。
- 币种、金额单位。
- 大标题、小标题、行名和列名。
- “其中”“其他”“合计”等项目的相关说明。
- 表前、表后对范围的解释。

**不要为了让文件看起来短，把标题和说明删掉，只留下数字。** 同一个数字放在不同的标题下面，含义可能完全不同。

### 空白不要提前处理

空白可能是：

- 这个位置有明确含义，但本次没填金额。
- 本次数据没有提供。
- 还没有明确具体成员。
- 原表中需要保留的模板位置。

这些情况不能全部当成零，也不能全部当成“这一格不用识别”。

### 单体和合并怎么处理

优先由识别阶段从附注、试算或其他实际资料中判断。

- **单体报表：** 只反映这一家公司自身。
- **合并报表：** 按合并范围反映公司及纳入范围的其他主体。

文件已经写清楚，就不需要你重复说明。确实没写，而你已经明确过的事实，应继续沿用已有记录。

窗口设置里有“报告口径”，其中“单户”对应这里说的单体。**这个设置会同时作用于两份表；如果两份资料口径不同，不要用一个选项把它们强行改成相同。**

窗口主要分成四块：

## 🚶 七、按五个步骤操作

### 📄 第一步：提取附注表格

**什么时候做：** 你从 Word 附注开始，而且还没有配套的附注表格和位置关联。

操作顺序：

1. 点击左侧 **“01 提取附注表格”**。
2. 在 **“原始附注 Word”** 一栏选择原文档。
3. 确认上方的成果保存位置。
4. 点击 **“提取附注表格与位置关联”**。
5. 结束后打开成果文件夹，保留提取后的表格及其位置关联。

**提取只负责把原始材料读出来，不按某个固定章节标题筛选。** 下一步由模型结合正文和你的明确要求确定参与更新的范围；读出来的表格不等于已经纳入更新。

这一步只是取出表格并记住位置，不调用模型判断财务含义，也没有把新数据填进去。

已有配套成果时，直接使用，不必重新提取。

### 🧠 第二步：识别附注表格语义

**这一步回答：附注需要哪些内容，各个待更新位置分别表示什么。**

操作顺序：

1. 点击 **“02 识别附注表格语义”**。
2. 选择 **“附注表格”**。
3. 有配套 Word 位置关联时，一并选入，便于带上对应的原文上下文。
4. 查看 **“文件未注明的信息（可选）”**。文件已写明的信息不必重复填写；只有确实掌握、而文件没有注明的共同事实才需要补充。
   同时填写 **“本次更新要求”**；已经保存的换期、名单更新等要求会继续带入。下方可选择本次不比较的主体、报表口径或金额倍率，原身份仍保留。
5. 点击 **“识别附注表格并保存答复”**。
6. 完成后保留 A合集及模型实际答复。

识别时，要把表头、相关说明和数据位置一起理解。空白业务位置仍在范围内，不让模型因为“没有金额”就自动排除。

已有正确结果继续复用。只有真实需要解决的错误或缺项，才处理对应范围；不因为某一项没解决，就把已经正确的整张表重新识别。

**这一步保存的是模型实际认出的内容。没有认出来的内容照实保留，不安排自动重答，也不要求你自己写一套复杂输出格式。**

### 🔎 第三步：识别更新数据语义

**这一步回答：为了满足附注需要，本期资料里有哪些可用来源，它们各自是什么意思。**

操作顺序：

1. 点击 **“03 识别更新数据语义”**。
2. 选择本期的 **“更新数据表”**。
3. 在可选输入中选择有效的 **“附注表格语义映射”**，也就是第二步的 A合集。
4. 文件没有注明但已经明确的共同事实，可以通过本步的补充信息带入。
5. 点击 **“识别更新数据并保存答复”**。
6. 完成后保留 B合集及模型实际答复。

程序先了解更新数据的工作表和业务编排，再根据 A需要缩小候选范围，详读必要内容。

普通入口会把范围认识交给模型，按它指出的范围提供相关金标准的完整定义及原文说明。指向同一项 A需要的候选来源一起交给模型确定实际采用哪一个；程序不按金额是否相同裁定来源。

来源对应、期间标签和名单关系在这次识别中一并确认，并保存到两个合集。第三步完成后，后面使用本步返回的两份合集，不再手工拼接某个科目的答复。

**“了解整份 B”不等于把整份 B 的每一个格子都重新识别。** 无关内容不应成为额外识别任务。

如果没有选入有效 A合集，B阶段只保存初步目录，不能把这个目录当作已经完成来源识别。

B的含义必须来自B自己的资料。不能因为A里有某个股东、某种范围，就直接把它填进B的识别结果。

### 🔗 第四步：建立单元格对应

**这一步回答：哪些目标能用哪些来源更新，哪些地方还缺什么。**

操作顺序：

1. 点击 **“04 建立单元格对应”**。
2. 选择 A合集和 B合集。
3. 确认它们属于本次资料和同一套适用标准。
4. 点击 **“建立对应并保存清单”**。
5. 查看保存的更新清单和执行记录。

新版入口会结合已保存的含义、维度、关系以及已有更新安排，形成机械匹配和更新清单。

它不应该重新问模型“这两格是不是同一个意思”，也不能仅凭标准编号相同就直接填数。

**当前新版入口的主要成果是更新清单。** 页面虽然保留了多种成果栏，并不表示每次都会同时生成一份可以直接打开的 Excel 明细报告。没有显示某种辅助文件，不能自行认定识别结果丢了。

#### 换期、名单要求填在哪里？

在提取、识别或建立对应页面的 **“本次更新要求”** 中，用平时说话的方式说明要求。例如：“沿用 A版式，日期和名单随 B更新，金额直接搬原值；没有来源的内容保留。”

“文件未注明的信息”是补充原文事实的位置，不是把所有更新要求塞进去的地方，更不能借此修改身份。

已保存的要求会随设置保留，传入 A识别、B识别及更新安排。下方的 **“本次不比较”** 只改变本次比较范围，不会把未知信息补成已知，也不会自动换算金额。已有接续作业继续沿用有出处的要求。

### 📝 第五步：生成更新后的附注

**这一步才会实际生成更新文件。**

操作顺序：

1. 点击 **“05 生成更新后的附注”**。
2. 选择本次已生成的 **“单元格对应清单”**。
3. 查看页面里的 **“当前清单绑定的来源”**，确认它指向本次附注和更新数据。
4. 需要 Word 结果时，使用与该清单配套的位置关联。
5. 在本次作业允许实际生成副本、相关依赖已经具备时，点击 **“生成更新后的附注”**。
6. 打开成果文件夹，查看实际生成的新文件及本次未执行事项。

具备相应条件时，输出包括：

- 更新后的 Excel 附注表格。
- 本次更新执行记录：分别引用原 A、B 合集，记录实际搬运值、标签和版式变化，不自动生成新的语义身份。
- 更新后的 Word 附注。
- 下一轮使用所需的新位置关联。

没有 Word 位置关联时，可以独立处理 Excel，但不能凭空生成可靠的 Word 对应位置。

新版写入流程允许已确定的动作与未解决事项分别保留。**即使生成了副本，也可能只是部分更新，必须看清哪些内容实际执行了。**

本步只执行两个合集和更新安排中已经确定的动作，不再调用模型理解含义或裁定来源。真实输出及保留事项以该次作业记录为准。

## ⚙️ 八、程序在后台怎样运行

整条主线可以这样读：

**原始资料 → 识别A需要 → 按需识别B来源 → 保存两个合集 → 机械匹配与更新安排 → 取值 → 写入新副本**

### 先确定范围，再认真理解范围里的内容

对一个需要识别的科目，先缩小相关标准候选。

例如，处理货币资金，就使用货币资金相关标准的完整定义，不把大量无关标准都重复发送。与此同时，要保留该科目实际需要的表头、段落和说明，不能把“少发无关内容”变成“删掉判断必需的上下文”。

已经确定的位置直接沿用，包括空白位置，不让模型重新猜一遍要看哪些格子。

### 模型负责理解财务含义

模型在A、B识别阶段完成判断：

- 对应哪个标准槽位。
- 原表具体表达哪些维度及取值。
- 哪些期间、范围和标签关系适用。
- 哪些地方有真实差异或缺信息。

金标准已经定义的内容直接作为依据，不另造一套重复定义。

不强迫模型照着庞大固定模板回答，不设置自动重答，不为了格式好看增加转换模型。

### 程序负责把已有答案接进合集

日期写法、坐标表示、明确引用等可以做机械整理，使已经识别的内容正常保存和使用。

但这种整理不能变成新的财务判断：

- 不能把未知改成一个猜测的范围。
- 不能给原答复补一个没有说过的关系。
- 不能拿旧的错误结论覆盖本次明确纠正。
- 不能因为答复格式略有不同，就把里面已经明确的内容吞掉。

### 后续只使用两个合集和明确要求

两个合集已经保存的含义，是匹配和编排的依据。

如果两边说法不同，但模型已经明确确认相同范围，并留下实际引用，程序可以使用这条关系进行比较，同时保留双方原来的说法。

如果没有这条关系，程序不能用文字相似、金额相同或位置接近来替代语义判断。

### 原表后面还会用到，但用途变了

识别之后，原表用于：

- 按确定位置核对和取得数值。
- 处理实际公式结果及其计算依据。
- 把内容写进新的副本。

它不应成为匹配阶段偷偷重新推断财务含义的入口。

保存和读取文件也不应演变成新一轮识别。已经有有效答复的机械接入问题，优先修好接入，不能反复调用模型碰运气。

## 🔄 九、几个最容易搞混的业务场景

### 📅 1. 换期：不只是把年份文字改一下

例如，附注原来列示“2024年期末”，现在需要列示“2025年期末”。

程序需要用已经识别的期间关系，确定新的期末数据应放在哪里，并把对应日期标题一起安排好。

- 财务项目可以不变。
- 日期取值会变化。
- 数据对应的期间角色要正确。
- 日期标题必须有明确的适用位置。

**知道金额属于哪一年，还不等于已经知道应当修改哪个标题。** 标题引用缺失时，应指出具体依赖，不应退回去把已经明确的金额含义重新识别一遍。

### 👥 2. 名单更新：名称和金额必须一起对应

例如，上一年股东是甲、乙，本年是甲、丙。

不能只把“乙”改成“丙”，却继续保留乙的金额；也不能看到B留了空白行，就把A里的乙自动填过去。

正确处理需要已经明确：

- B实际提供了哪些成员。
- 每个成员对应哪些金额和其他字段。
- A需要怎样呈现本次名单。
- 行数变化时，使用哪一段已有表式进行安排。

新的股东姓名通常是已有投资者维度的新取值，不是自动增加一个财务槽位。

**B里有一个未采用的来源，也不等于必须给附注新增一行。** 是否纳入本次更新，要有实际范围和明确要求。

### 📋 3. 原值搬运：照已经确定的要求搬

有些比较数或其他信息，需要把A里的原值搬到新位置。

这种动作使用已经明确的来源、目标和期间安排，不应再次让模型判断一遍已经确定的含义，也不应顺手改写原来的数值。

如果没有明确应从哪里搬到哪里，不能只因为两个位置挨得近就自动移动。

### ⬜ 4. 空白、零和没有资料，是三回事

| 情况 | 应怎样理解 |
|---|---|
| 原表明确写了零 | 这是实际的零值 |
| 位置为空白，但表头含义明确 | 含义仍然需要保留，金额未填 |
| B没有提供相应数据 | 没有可搬运的新值，不能擅自填零 |
| 原文不足以确定业务含义 | 保存具体未知，只停止依赖它的动作 |

当前新版处理中，B为空白时会保留A原值并记录原因。**保留原值不等于本期数据已经更新。**

### 🧮 5. 合计、父项和“其中项”不能互相顶替

“应收账款合计”和“其中某一类应收账款”可能使用相关标准，但范围不同。

“存货合计”也不能直接替代某一类存货金额。

范围是否包含某些项目，必须依据金标准和真实资料在识别阶段确认。不能让后续程序为了找到来源，把父项和其中项混成一个东西。

### 🧷 6. 本次不比较某项，不等于这项身份可以丢

当前已确认的比较排除包括主体、报表口径和金额单位倍数；适用范围以这次作业已经保存的要求为准。

这些信息仍应如实保存在各自合集里。缺失仍是缺失，不能因为本次不把它作为比较条件，就自动补成“相同”或“已完整”。

排除金额单位倍数也不等于自动换算金额。不能把“暂不按这一项筛选来源”理解成“元和万元可以直接当成相同数值”。

同样，人工指定一个来源，也不能替代尚未确定的业务身份。

- Word与Excel是否使用同一份更新安排。
- 本次没有处理的章节是否被误认为已经更新。

这是理解交付结果，不是再增加一轮模型核查。

## ♻️ 十一、怎样复用成果和接着上次工作

### 已经做过的步骤，不必再做一遍

| 手头已有的材料 | 下一步通常从哪里开始 |
|---|---|
| 附注表格及位置关联 | 识别附注，或直接复用已有A合集 |
| 有效的A合集 | 按A需要处理B |
| 有效的A合集和B合集 | 沿用本次要求，建立对应 |
| 本次有效更新清单及配套材料 | 在允许写入且条件具备时生成副本 |
| 已更新表格及配套执行记录、原两份合集 | 准备下一轮使用，复用仍适用的原判断 |

### 保留完整成果文件夹

不要只留下最后一份表格，把合集、位置关联和清单配套材料全部移走。

这些文件互相引用。文件被单独移动、来源换成另一个版本，可能导致原来保存的关系不能继续使用。

换了原件或标准以后，应判断哪些旧成果仍适用。不能因为文件名没变，就继续把旧结果当成本次结果。

**不要选择“最近修改”的文件就直接继续。** 最近保存的可能是局部试验、失败记录、旧答复重读结果，也可能只包含一个科目的修正。

## 🛠️ 十二、遇到问题怎么办

### 双击启动后没有窗口，或者一闪就没了

先确认项目已经解压，打开的是完整项目文件夹。

如果提示缺少运行环境，再使用“准备运行环境.cmd”。保留窗口里的具体错误，不要连续重复安装或启动多份程序。

### 选择了文件，但按钮仍然不能执行

看页面下方是否提示“尚缺”或“本步缺少材料”。

常见原因是：选的是原始表格，但当前步骤需要的是已经保存的语义合集；或者选择的成果不属于本次A、B。

### B为什么只生成了目录？

先确认第三步有没有选入有效A合集。

没有A需要，程序只能初步认识B的编排，不能把目录当作完整来源识别成果。

### 模型明明说了，结果却没有进入合集

先对照已经保存的原答复，确认是模型没有给出，还是日期、坐标、引用等表示方式没有被程序正确接入。

**原答复里已经明确的内容，应优先修好接入，不应立刻重新调用模型。**

如果原答复本身说的是未知，就不能把它算成“程序漏接了一个确定答案”。

### 两边是同一个标准编号，为什么还不能对应？

标准编号说明它们属于哪个财务项目，但还要看实际维度和范围。

例如，同一项目可能分别是期初、期末；也可能分别是全部范围和其中一部分。编号相同不是直接搬值的充分条件。

### 已经选定来源，为什么还不能换期？

可能缺少需要一起改动的期间标题位置，或标题与数据的明确关系。

这时应保留已经选定的来源，并说明具体缺哪个引用，不能笼统退回“模型没有识别”。

### 股东名称空着，为什么不能直接用旧名单？

旧名单只说明A过去列了谁，不能证明B本期提供的就是这些人。

如果已有原文或答复能确定成员，继续接入；确实没有，就把缺的成员事实留下。不能由程序填一个看起来合理的人名。

### 空白金额是不是零？

不是。空白与零必须分别保留。

B没有金额时，也不能因为想让表格显得完整，就自动把A改成零或清空。

### Excel里看得到公式，程序却拿不到有效金额

公式表达式与已经计算保存的结果是两回事。

应检查是否已有可用的计算结果或有效的计算副本。需要重新计算时，使用副本并保留原件；这属于机械取值，不是重新判断财务含义。

### 为什么有Excel结果，没有Word结果？

先看是否提供了与本次附注表格配套的位置关联，再看Word生成步骤是否报错。

只有Excel更新成功，不代表Word也已经完成。应分别确认实际输出。

### 提示成果或来源已经变化，能不能直接改状态继续？

不要只改“通过”“完成”等文字。

先找到变化的具体文件，以及它影响的已保存关系。真正需要的是让文件、合集和清单重新对应起来，不是把提示隐藏。

### 已经有一部分能更新，为什么还说“部分完成”？

因为程序可能执行了确定的动作，同时保留其他未执行事项。

“部分完成”不等于整次工作毫无结果，也不等于剩余事项可以忽略。要看实际完成了哪个主线环节、哪些动作没有执行。

### 暂停以后，之前的成果会不会没了？

已保存的文件应保留。当前正在处理但尚未保存的部分，要看本步结果，不能假定一定已经完成。

重新接续时优先找有效合集和清单，不要把暂停等同于必须从头识别。

## ⏱️ 十三、速度和费用应该怎样控制

这套流程应把模型调用集中在真正需要语义判断的范围。

具体做法是：

- 根据科目和已有范围缩小标准候选，保留相关标准的完整定义。
- 只发送必要范围及其完整上下文。
- 已确定的位置、空白和正确结果直接复用。
- 一个必要识别范围一次作答，不自动重答。
- 已有答复能解决的问题，用已有答复接通。
- 匹配、编排和写入使用两个合集及明确要求，不再增加转换模型。
- 不因为某个无关事项未知，就反复读取和识别整份资料。

**一次必要范围一次作答，不代表整份大型工作簿只能发出一个请求。** 范围认识和不同业务范围可能分别需要处理，但不能围绕同一个问题反复追加重复流程。

目前没有足够的完整实测依据，承诺“整份报告固定几分钟完成”或“固定花费多少钱”。

应记录实际耗时、实际模型用量以及复用了哪些已有成果。速度变慢时，先找是材料过大、服务等待、重复读取还是保存接入的问题，不把“再跑一遍”当作通用办法。

## 🧰 十四、文件夹里的其他工具，要不要都运行

**不用。正常附注更新围绕主窗口的五步进行。**

| 工具 | 主要用途 | 是不是主流程前置条件 |
|---|---|---|
| 体验结构初筛 | 用虚构小表体验怎样找相似表式，不调用模型 | 不是 |
| 准备初筛索引 | 利用已有配套资料建立表式参照 | 不是每次更新都要做 |
| 程序验证工具 | 检查特定程序行为 | 普通使用者不需要每次全部运行 |
| 金标准修订功能 | 保存经过确认的新标准版本 | 普通附注更新不需要修改标准 |

结构初筛找到的只是表式线索，不能直接代替财务含义识别。

旧索引不可用，也不能因此把重建所有历史资料变成当前更新任务的前置工作。

后台运行能力不要求模拟鼠标点击，但当前普通使用说明以窗口操作为主。接续这次作业时，应使用已确认的当前入口，不恢复旧流程。

## 🔒 十五、原件、资料和使用边界

程序的输出目标是新副本。原始附注、更新数据、金标准以及历史答复，应保留原样，方便追溯。

涉及修改已有程序或既有成果时，先保留经校验的备份。日常使用者不需要为了“修好结果”直接编辑内部成果内容。

语义识别会把相关材料发送给已配置的模型服务；匹配和副本生成本身不需要额外语义调用。模型服务的登录、用量和费用以实际使用情况为准。

公开交流问题时，描述所用步骤、预期结果和实际提示即可，不要公开客户原始资料或访问密钥。

项目使用许可与第三方材料说明，以随附的许可证和来源说明为准。本使用说明不改变这些条款。

## ✅ 十六、最后怎样判断系统真正做通了

最终目标不是攒出很多识别记录，也不是让所有按钮都能点。

**真正做通，是从正常入口使用原始附注和本期数据，按既定要求生成正确的整份附注副本；能保留明确未处理的事项，能够继续下一轮，并在另一套资料上验证可以复用。**

这需要把以下事情连起来：

1. A需要和B来源的财务含义识别正确。
2. 已经明确的内容完整进入两个合集。
3. 换期、名单更新、原值搬运和比较要求被实际使用。
4. 来源与目标正确对应，日期、名称和金额一起安排好。
5. Excel与Word副本实际生成，结果与安排一致。
6. 正确成果能够带入下一轮，而不是重新从零开始。

**当前正在向这个目标推进。已经修好的一段就继续复用，尚未完成的一段如实说明，不用格子数量代替整条主线的完成情况。**
